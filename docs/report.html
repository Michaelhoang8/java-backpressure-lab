01 / TASK LIFECYCLE

Admission and shutdown semantics

BLOCK

Wait for queue capacity using a condition and a bounded wait budget. Reject on timeout, interruption or closure. Restore an interrupted caller's flag.

REJECT

Reject a full waiting queue after acquiring the state lock; never wait for queue capacity. No caller-runs fallback and no hidden unbounded queue.

OPEN → CLOSING → TERMINATED

Closure rejects new ownership and wakes blocked submitters. Workers drain admitted work. Running tasks are not forcibly interrupted.

Only queued tasks can be cancelled. A task failure is recorded before the worker continues.

attempted = admitted + rejected + waiting submitters
admitted = queued + running + completed + failed + cancelled

05 / IMPLEMENTATION AND REPRODUCTION

Implementation and measurements

Implementation

ReentrantLock, conditions, a bounded ArrayDeque and owned worker threads. Latches establish queue saturation in tests. Python compiles/runs Java and plots recorded results.

python scripts/run_study.py
python scripts/run_study.py --quick   --output-dir build/my-run

Raw task timestamps, occupancy observations, JDK metadata and source hashes are committed.

Measurement limits

Local finite synthetic workloads. Requested 2 ms service delay and 4 ms paced-producer pause can overshoot with OS scheduling. One trial per scenario in fixed order; JIT warmup and order are confounders. No JMH-grade isolation.

Queue capacity bounds waiting work, not lifetime telemetry retention. Fatal VM failures are outside the recovery guarantee.
